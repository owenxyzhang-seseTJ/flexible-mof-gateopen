# 只评价空框架自由能：MOFSimBench 能支持什么结论？

本文件仅讨论没有吸附客体时的框架 Helmholtz 自由能 F_host(T,V)、相内最小化后的自由能，以及同一 MOF 开孔/闭孔间的 ΔF_host(T)。不使用吸附能或储气相性质给模型排名。

依据：Kraß, Huang & Moosavi, **MOFSimBench: evaluating universal machine learning interatomic potentials in metal-organic framework molecular modeling**, npj Computational Materials **12**, 4 (2026), [DOI 10.1038/s41524-025-01872-3](https://www.nature.com/articles/s41524-025-01872-3)。在线发表于 2025-12-11，正式卷年 2026。正文及官方代码核对日期：2026-09-13。

## 1. 最重要的结论

**这篇文章没有直接给出柔性 MOF 两相 ΔF_host(T) 的预测误差或排行榜。**它支持选择较可靠的势能面候选，但不能证明其中某个模型已经准确预测 MIL-53 或 X-pcu-5-Zn 的空框架相对自由能。

其与空框架最相关的评测是：结构优化、短时间 MD 稳定性、体模量 K 和比热容 Cv。后两项分别检验体积形变及原子位移方向的局部势能曲率；不是两相间的能量基准，也不是完整相空间积分。

## 2. 与框架自由能有关的直接证据

以下只列原文报告且与空框架有关的指标。模型元素覆盖和成功样本集合不完全相同，不能忽略失败结构，仅拿 MAE 作绝对排名。

| 候选 | 原文空框架证据 | 对 ΔF 的合理解读 |
|---|---|---|
| eSEN-OAM | 体模量 MAE 2.60 GPa、MAPE 20.8%；Cv MAE 0.024 J g⁻¹ K⁻¹；几何/MD 表现靠前 | 适合优先验证相内 E(V) 与稳定性；未验证跨势阱 ΔE/ΔF |
| orb-v3-omat（保守力版本） | Cv MAE 0.018 J g⁻¹ K⁻¹、MAPE 2.3%；体模量 MAPE 23.4% | 振动热力学值得优先验证；Cv 好不代表低频熵与相对自由能一定好 |
| MACE-MP-MOF0 | Cv MAE 0.020 J g⁻¹ K⁻¹；体模量 MAE 3.16 GPa；四个原型 MOF 的体模量表现好 | MOF 专用对照，但 100 结构集中 28 个因元素覆盖不支持；不保证适合目标 MOF |
| MACE-MP-0a | Cv MAE 0.082 J g⁻¹ K⁻¹；存在体模量低估/势能面软化 | 不应仅因易安装或能跑就作为框架自由能的首选 |
| orb-d3-v2、eqV2-OMsA | 非保守力，优化/E(V) 存在问题；体模量 MAE 分别 72.29、11.11 GPa | 不优先用于依赖一致能量梯度的声子和 MD 自由能路线 |

注意：当前软件测试里的 **MACE-MP small** 不等同原文的 MACE-MP-0a 全部配置；CHGNet 没有出现在该文列出的 20 模型评测架构中。不能把上表指标归给当前 CHGNet 或 small 后端。

原文所有被评测的 uMLIP 要么在推理时加 D3，要么训练目标已含 D3。当前 Si 接口测试没有加 D3，不能因此宣称复现了文章的 MOF 表现。MOF 专属 MACE-MP-MOF0 已学习含 vdW 的目标时，再叠加 D3 会重复计数。

进一步追溯 [MACE-MP-MOF0 原始研究，DOI 10.1038/s41524-025-01611-8](https://www.nature.com/articles/s41524-025-01611-8)：其摘要明确提出 MOF 的声子/准谐工作流，报告相较基础 MACE-MP-0 改善声子态密度、修正虚频，并测试热膨胀和体模量。这比单纯结构优化更接近 F_vib 的需求，但仍不能替代目标柔性 MOF 两个势阱间 ΔF 的直接基准。本轮读取了该原始研究摘要/引言；未声称完整复现其声子评测。

## 3. 为什么 Cv 准不能保证 ΔF 准？

两相在同一 T 下：

`ΔF_host = ΔE_static + ΔF_vib + ΔF_anharmonic + ΔF_configurational + ...`

这里各修正必须在一致的参考和统计约束下定义，不能把不同模型的单项随意相加。

**反例 1：相间能量偏移。**若模型把开孔势阱整体抬高 5 kJ/mol-f.u.，但井内形状完全正确，则力、结构、局部声子和 Cv 都可正确，ΔF 仍偏差 5 kJ/mol-f.u.。因此必须直接核验同一 MOF 两相的相对能量。

**反例 2：软模熵。**在 ℏω≪kBT 的经典极限，一个模式的 `F_vib≈RT ln(ℏω/kBT)`，而 `Cv≈R`。频率错一倍，Cv 仍接近同一个 R，但 300 K 下该模式的自由能约错 `RT ln2≈1.73 kJ/mol`（模式按每个重复单元计数时还需正确归一）。许多低频模式的小偏差会累积；开闭孔之间是否抵消必须计算，不能假设。

从 `Cv=−T(∂²F/∂T²)_V` 积分恢复 F 还需要能量及熵参考。单个温度的低 Cv MAE 尤其不能确定相间自由能偏移。对于室温 ΔF 的 1 kJ/mol-f.u. 目标误差，仅熵项就需要把 ΔS 的误差控制在约 3.3 J/mol-f.u./K 内（前提是能量误差已另行控制）。

## 4. 针对框架自由能的模型选择

推荐**候选验证顺序，不是已证明的 ΔF 排名**：

1. eSEN-OAM 与保守力 orb-v3-OMAT：分别完整算一套 ΔE + ΔF_vib(T)，检查相态稳定性；依照各 checkpoint 要求一致处理 D3。
2. 目标元素受支持时，加入 MACE-MP-MOF0 作为 MOF 专用对照。
3. 当前已经跑通的 CHGNet/MACE 通用模型保留为接口基线或敏感性对照，不根据 Si 测试直接升级为最优 MOF 自由能模型。

不要把 eSEN 的 ΔE 与 orb 的振动熵拼成一个未经定义的“最优结果”。应分别在各自势能面上完成相同流程，再比较预测的 ΔF；模型间一致只说明敏感性较小，并非独立验证。

非保守力模型并非数学上不能用其能量做 Metropolis MC，但能量和力不一致会使优化、声子、MD 与 MC 实际使用不同的势能面。本工作流因此优先采用保守能量梯度模型。

## 5. 最小而有意义的目标材料验证

必须先有同组成、同活化状态、无序/溶剂处理合理的开孔和闭孔结构。

- **ΔE：**在相同几何与相同 DFT 理论级别下，比较 ML 的开闭孔能差；避免先混用不同几何再把误差归因于势函数。再单独测试各相受限松弛造成的变化。
- **势阱：**对两相附近少量压缩/拉伸及内部位移点，核验 E(V,q)、力和应力；确认两相都保留，未产生虚假的低能坍塌。
- **谐振 ΔF：**分别计算稳定两相声子。比较 ΔF_vib(T)、低频模和 ΔS，而不只看 Cv。检查虚频、超胞、位移幅度、q 网格收敛。
- **非谐项：**若呼吸/转动软模使谐振近似失效，转向相内约束采样和可控的 TI。不同相的固定粒子、坐标范围及有限尺寸修正必须一致或显式校正。
- **验证目标：**输出每个温度的 `ΔF_host ± 数值/采样误差`，另列 DFT 理论级别、模型泛化和约束误差；不要将模型差异伪装为统计标准差。

只有 ML、没有相对能 DFT/可靠文献或独立热力学参考时，可以输出 **ML 估计及模型敏感性范围**，不能给出“预测误差已小于若干 kJ/mol”的结论。

## 6. 当前集成能证明什么？

CHGNet/MACE 单点、CHGNet→Phonopy 与受约束 MC-TI 已实际运行；解析谐振和双势阱验证说明数值实现具备基本一致性。

**还不能证明当前任何后端对目标柔性 MOF 的 ΔF_host 准确。**Si 后端测试不承担 MOF 精度验证；受约束 MC 的短链只承担调用链验证。原文有助于重新选择候选模型，但尚不能替代上述两相 ΔF 验证。
