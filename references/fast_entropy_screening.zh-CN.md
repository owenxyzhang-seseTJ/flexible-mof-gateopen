# 不做 MD/DFT 的框架自由能快速筛选

## 定位：数秒级代理模型，不是新的高精度自由能方法

按用户约束，本路径不启动 MD、DFT、量子电子结构优化、有限位移 ML 声子或框架
MC 采样。使用已清理的两相结构、已有静态框架 ML 势能，以及一个独立的周期弹性
网络模型估算振动熵。结果明确标为 `fast_unvalidated_multifidelity_screen`。

**重要：静态 ΔE 和振动项来自不同模型。**这是多保真初筛，不是同一 ML 势下严格
自洽的 F；网络具有正本征值也不能“修复”原 ML 势的虚频或证明真实相稳定。
目前没有用 MOF 开闭孔熵差数据校准，因此不能给出已知精度或可信误差条。

## 如何估算熵

1. 从原子元素、距离和周期连接建立共价、X–H、金属–配位原子连接。
2. 为每条连接设置纵向弹簧，以及较弱的横向恢复力，近似描述键角/铰链阻力：

   `K_ij = k_parallel [n nᵀ + α(I − n nᵀ)]`。

   横向项是经验代理，不是从完整 MOF 力场推导的键角 Hessian。
3. 对非键合重原子接触添加平滑衰减的弱接触弹簧；排除真正的周期 1–2、1–3 对。
4. 用周期相位 `exp(i2πq·S)` 和原子质量构建 Hermitian 动力学矩阵，直接对角化。
   不移动结构、不调用电子结构计算，也不做温度轨迹采样。
5. 对网络的正频率使用谐振子统计求代理 S、U_vib、F_vib。只去掉 Γ 点的三个
   已知平移零模；其他零模/负本征值报错，不任意取绝对值或设置频率下限。

`x=hν/(kBT)` 时：

`S_proxy = R Σ_qj w_q [x/(exp(x)−1) − ln(1−exp(−x))] / Z`

`U_vib,proxy = RT Σ_qj w_q x[1/2 + 1/(exp(x)−1)] / Z`

`ΔF_screen = ΔE_static + ΔU_vib,proxy − T ΔS_proxy`。

这里依然没有省略振动内能与代理零点能；不是简单把静态 ΔE 减 TΔS。
绝对熵不应当作真实 MOF 熵；差值也不因常数抵消而自动准确。

默认弹簧仅是明确可修改的启发式参数（eV/Å²）：共价 15、X–H 40、金属配位 3；
横向系数 0.03、接触强度 0.03、接触截止 4.5 Å。它们**不是现成的已验证 MOF-FF**。
程序自动比较横向系数 0.01/0.03/0.1、接触强度 0/0.03/0.1 的五种组合。
该范围是参数敏感性，不是统计置信区间，更不涵盖全部模型误差。

弹性网络方法的一般思想可参考 Atilgan et al., *Biophysical Journal* 80, 505–515
(2001), DOI [10.1016/S0006-3495(01)76033-X](https://doi.org/10.1016/S0006-3495(01)76033-X)。
该论文研究蛋白质；本项目的周期版本、横向弹簧与参数是筛选实现，**不能把该引用
当成 MOF 熵精度验证**。本轮核对了该文元数据，并非复现其全部算法。

## 本次真实快速结果：MIL-53(Al)，268 K

仍使用之前通过结构审核、固定晶胞优化后的两相，每个 CIF 有 4 个 Al(OH)(BDC)
化学式单元。只重新评估两个静态能量点；没有执行新的 MD、DFT 或结构优化。

| 项目，开孔减闭孔 | 3³ q 网格 | 4³ q 网格 |
|---|---:|---:|
| 静态 ΔE，kJ/mol-f.u. | +13.45907 | +13.45907 |
| 基准 ΔS_proxy，J/mol-f.u./K | +1.16227 | +1.15615 |
| 基准 ΔF_screen，kJ/mol-f.u. | +13.13149 | +13.13313 |
| 五组参数的 ΔF 范围，kJ/mol-f.u. | 12.8715–13.2822 | 12.8731–13.2831 |
| 实测执行时间 | 5.17 s，含载入 ML 势并算两个静态点 | 3.63 s，复用哈希匹配的静态能量 |

数值 q 网格敏感性很小，但这只验证了**代理模型的数值积分**，不验证真实熵。
例如，3³ 基准模型给出的两相绝对代理熵约 416/418 J/mol-f.u./K；不能将它们作为
实验或可信声子绝对熵引用。参数扫描也不能证明真实 ΔF 一定落在 12.87–13.28 区间。

可用解释：在这组网络假设下，开孔相熵略高，但熵收益不足以抵消正的静态能差。
不可用解释：已经证明真实材料 ΔF=13.13，或已经验证真实 gate-opening 压力。

## 命令与配置

```bash
python scripts/quick_host_free_energy.py --spec quick_host.json --out output/host_proxy.json
```

```json
{
  "temperature_K": 268,
  "mesh": [3, 3, 3],
  "calculator": {"backend": "mace", "model": "/path/to/mofs_v2.model", "head": "pbe_d3", "dispersion": false},
  "states": [
    {"name": "closed", "cif": "closed.cif", "cleaning_report": "closed.cleaning.json", "formula_units": 4},
    {"name": "open", "cif": "open.cif", "cleaning_report": "open.cleaning.json", "formula_units": 4}
  ]

```

若已有该脚本输出或 `advanced_free_energy.py host-energy` 的输出，可用
`static_energy_json` 代替 `calculator`；程序核对相名、CIF 哈希和 Z 后复用静态能量。
因此对已计算的候选做温度、弹簧参数或 q 网格扫描时，连 ML 能量推断也无需重跑。

完整工作流设 `host.method="elastic-network"`，可指定 `host.proxy_mesh` 和
`host.proxy_parameter_sets`。上传界面已把这个方法设为快速筛选选项。原声子路径仍
可显式选择，但本快速模式不调用它，也不会自动改用 MD/DFT。

## 推荐筛选规则

- 用于比较候选及标出对熵假设敏感的体系，不凭这个代理值给出精确 gate pressure。
- 若更换弹簧/接触参数会改变 ΔF 符号，则标为“不确定”，不强行排序。
- 若两候选差值与参数敏感性接近，视为无法区分；即使差值较大，也要保留共同的
  模型偏差风险，尤其是不同化学组成、拓扑或柔性机制之间。
- 未采样构象、无序和相变路径熵没有包含。晶体学占有率不能直接代替热力学概率。
- 如需提高筛选可靠性而仍禁止 MD/DFT，应使用已有文献/公开数据的 ΔS 或 ΔF
  作为外部校准与留出验证；本轮不捏造尚未建立的校准集或精度。
