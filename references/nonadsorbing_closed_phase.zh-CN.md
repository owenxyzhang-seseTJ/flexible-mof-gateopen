# 闭孔相不吸附：快速筛选的正确处理

## 结论与热力学

闭孔可以不吸附；开门并不要求气体先进入闭孔。开孔相的吸附收益足以支付框架
打开的自由能代价时，体系的平衡稳定态可以改变。实际转变可能从表面、缺陷或
局部开孔区域成核，但两端点模型不预测这些动力学步骤或能垒。

以开孔减闭孔、每摩尔相同框架化学式单元定义：

\[
\Delta\Omega=\Delta F_{host}+P\Delta V
-RT\int_0^{f(P,T)}(N_{open}-N_{closed})\,d\ln f.
\]

当明确采用不吸附闭孔模型时，`N_closed=0`、`Omega_ads,closed=0`，因此直接计算
开孔吸附积分即可。闭孔的框架自由能仍然必须计算，**不吸附不等于框架 F=0**；
代码中把闭孔 F 设为参考零点，仅表示只使用两相差值。

三种情况必须分开：

- 真正无容纳位点：可以采用零吸附模型；有限能量力场下通常应称近似可忽略。
- 孔口很小、内部却有腔体：这是扩散可达性问题。GCMC 可以绕过孔口直接插入腔体，
  不能用孔限直径小于客体直径就证明平衡吸附为零。
- 随机插入失败或采样不足：检查客体几何、重叠阈值、单位、原子类型、电荷、
  Widom 的实际构造次数与独立种子。不要将输出 0±0 当作精确物理零。

## 快速排查，不做 MD/DFT

1. 复用已 clean-cif 审核、已赋电荷的框架，以及已审核的客体/力场。
2. 空框架 Widom：固定零客体，只进行测试插入，独立种子重采样位置和取向。
   这里的零占据数由算法强制，不能拿来证明不吸附。
3. 使用 Widom 的 Henry 系数估计低密度尺度，评估种子间变化；若稀有有利构型
   主导平均值，增加取向/空间重要性采样或空腔定位。不要只增加同一随机序列的压力点。
4. 显式比较 `N_closed=0` 与 `N_closed=K_scenario*f` 的假设情景，必要时把 K 放大
   10、100 倍。线性情景的积分精确为 `Omega_ads,closed=-RT*K_scenario*f`，
   不用粗糙对数压力梯形积分近似线性 Henry 曲线。
5. 如果这些情景显著改变相变压力，不能忽略闭孔吸附。若存在可能的协同填充，
   可进一步采用空腔/取向偏置插入、CBMC、连续分数分子或平坦直方图 GCMC；必须
   使用带正确偏置校正/详细平衡的实现。本次仅执行普通空框架 Widom，并未声称
   实现后面这些增强采样。怀疑亚稳高负载态时需不同初始负载的对照，不能随意塞入
   重叠客体后把不收敛轨迹当平衡结果。

**重要限制：Widom 只给无限稀释 Henry 系数。**它不能排除高压协同吸附/凝聚，
也不能给任意压力下的严格吸附上界。`max(均值+原生 confidence)` 仅用于定义一个
可复现的敏感性尺度；不是保证上界，原生 confidence 也不是标准差。只有在另有
依据支持“整个范围 N≤Kf”时，才可把 `RTKf` 作为相应假设下的积分上界。

## 本次 MIL-53(Al)/CO₂，268 K 的实跑结果

复用原始 `mil53_workflow_run3` 的已审核输入，保持力场、结构、电荷、客体和
1×3×3 闭孔超晶胞不变；只新运行空框架 Widom。4 个独立种子，每个 10,000
production cycles（原生输出每个 200,000 MC steps），总耗时约 109 秒。

| 种子 | K，分子/f.u./bar | RASPA 原生 confidence，同单位 |
|---|---:|---:|
| 1729 | 2.070662×10⁻⁶ | 3.944958×10⁻⁷ |
| 3253 | 2.323820×10⁻⁶ | 3.194910×10⁻⁷ |
| 5801 | 2.121827×10⁻⁶ | 4.224483×10⁻⁷ |
| 7919 | 1.932261×10⁻⁶ | 4.759233×10⁻⁷ |

定义情景尺度 K*=2.643311×10⁻⁶。20 bar 的实际逸度为 17.2071 bar，仍低于
CO₂ 饱和蒸汽压约 30.3336 bar。沿用 ΔF_proxy=13.1331 kJ/mol-f.u. 和已有短程
开孔等温线，采用真实逸度及 PΔV，得到：

| 闭孔假设 | 20 bar 下闭孔负载，分子/f.u. | 条件性 P_eq，bar |
|---|---:|---:|
| N=0 | 0 | 5.99997 |
| N=K*f | 0.00004548 | 6.00002 |
| N=10K*f | 0.0004548 | 6.00044 |
| N=100K*f | 0.004548 | 6.00469 |

表中额外小数仅用于比较数值情景，不代表材料压力精度。100 倍情景使 P_eq 上移
约 0.00471 bar（0.079%）；闭孔稳定化在扫描终点约 0.0101 kJ/mol-f.u.。
**因此当前模型下，忽略低水平闭孔吸附是合理的初筛近似。**该结论仍以没有漏掉
强协同填充/重要稀有位点为条件，也不自动适用于其他闭孔材料。

真正尚未收敛的误差更大：

- 网络弹簧参数情景对应 P_eq≈5.65–6.21 bar；不包含全部框架自由能模型误差。
- 将开孔各点负载按原生 confidence/种子差尺度同向扰动，P_eq≈4.34–8.49 bar；
  这是人为敏感性扫描，不是统计置信区间。
- 用拟合 Langmuir 曲线替代原始分段积分约得 5.78 bar；仅为稀疏网格下的模型
  敏感性，不能证明拟合曲线正确。
- 原开孔数据每点只有 200 production cycles；主机自由能仍为未校准的静态 ML
  + 独立弹性网络代理，原 ML 声子不稳定问题未解决。约 6 bar 只能作为条件性
  平衡筛选值，不能称为准确实验开门压力，也不预测迟滞。

实际完整数据保存在本地 `output/closed_exclusion_widom/result.json` 和
`output/closed_exclusion_screen/result.json`，含来源哈希、原生输出和情景明细。

## 工作流配置与复现

在 `workflow.json` 中显式加入（示例数值仅适用于上述案例，换体系需要重审）：

```json
{
  "adsorption_models": {
    "closed": {
      "kind": "nonadsorbing",
      "interpretation": "conditional_scenario",
      "evidence": "Run-specific empty-host Widom audit and explicit negligible-uptake assumption",
      "max_fugacity_bar": 17.2071141095536,
      "sensitivity_K_molecules_fu_bar": [0.000002643311, 0.00002643311, 0.0002643311]
    }
  }
}
```

此配置替代闭孔的插入/Henry 检查；不替代开孔收敛和框架 F 检查。若闭孔已有
正负载数据，零吸附分支会报告矛盾并阻止放行；不能覆盖实际吸附数据。无显式配置
的零负载仍会触发审查。程序保留零负载相互作用能不可辨识的结果，不伪造拟合能。

```bash
python scripts/run_empty_widom.py \
  --source-point /path/to/verified/closed/point \
  --checkpoint /path/to/raspa_closed/completed.json \
  --binary /path/to/raspa3 --formula-units 4 \
  --out output/new_widom --cycles 10000 --seeds 1729 3253 5801 7919

python scripts/screen_closed_exclusion.py \
  --spec output/closed_exclusion_screen/spec.json \
  --out output/new_closed_sensitivity.json
```

后一个脚本是诊断入口，明确允许带说明地重用未收敛的开孔曲线进行情景计算；
它不会把正式工作流中尚未通过的 Henry/收敛审查改成已验证结果，也不修改旧输出。
所有新运行使用新目录，没有启动 MD、DFT 或新的主机声子/结构优化。
