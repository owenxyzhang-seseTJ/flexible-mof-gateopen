# MIL-53(Al) + CO2 osmotic benchmark

This is a compact published-parameter benchmark, not a claim of an atomistic flexible-host calculation. The model uses the narrow-pore/large-pore Langmuir parameters and host term reported by Boutin et al. At 223 K the higher equilibrium branch is approximately 0.01696 bar.

The included CSV and plot are useful for checking the sign convention and the two-state crossing implementation before using a real RASPA dataset.
