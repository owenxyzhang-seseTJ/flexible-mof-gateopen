# MIL-53(Al)/CO₂ 完整工作流实跑记录

## 结论

**软件全链路已实际执行，材料的可信自由能差和开门压力尚未获得。**
本记录不把静态能差、假定熵或条件拟合包装成最终开门压力。
数值及出处保存在 [validation_summary.json](validation_summary.json)。

后续按“不做 MD/DFT、快速筛选”的要求新增了
[弹性网络代理熵路径](../../references/fast_entropy_screening.zh-CN.md)，得到约
13.13 kJ/mol-f.u. 的快速 ΔF 代理估计。它使用不同于静态能的振动模型，尚未校准；
不改变本记录中“同一 ML 势的可靠 ΔF 未取得”的结论。

## 本轮发现并修复的问题

- PACMOF 旧写出器截断分数坐标：改为只写入电荷列，保留几何、晶胞和占有率。
- sklearn 版本与 PACMOF 模型不一致：直接拒绝；本机运行锁定 1.8.0。
- MACE-MOF0-v2 有多个 head：显式选择 `pbe_d3`，禁止再次叠加 D3。
- MMFF 对 CO₂ 虽然收敛，却给出约 1.405 Å 的错误 C–O 键长：增加独立几何检查，
  该轮等温线不用于当前结果；换成 GFN2-xTB 精修后重跑全部吸附点。
- torch/tblite 在 macOS 的 OpenMP 冲突：使用独立子进程，而非启用不安全的重复库开关。
- RASPA 超晶胞归一化：交叉验证 molecules/cell 与 molecules/uc，能量与吸附量均按
  Z×超晶胞倍率归一化；原生置信区间不冒充标准差。

## 自由能为何仍然失败

开孔相在 **Γ 点已有约 −5.08 THz 虚频**；因此不能只把问题归咎于 q 点采样。
固定晶胞、对称起点的力优化收敛，不足以证明找到了势能局部极小点。
闭孔相 Γ 点接近稳定，但区界存在虚频，需要扩大位移超晶胞排查短程力常数截断。
本次采用 1×1×1 位移超晶胞，仅用于检测软件接口，不能证明真实声子色散。

下一轮应先沿不稳定模/小幅扰动寻找保持各相体积与化学连接的稳定构象，收紧残余力，
扩大声子超晶胞并做收敛检验。若相在所选框架势下仍不稳定，应换经材料验证的势或
采用经验证的非谐自由能采样，而不是删除虚频或凭空补熵。

闭孔相无接受插入还需孔道/客体尺寸、势参数及 Widom/增强插入采样审查；低压点需要
更长模拟确认 Henry 极限。8 Å 截断、200 生产周期属于短程测试，不是定量方案。

## 使用入口

参考 [完整配置说明](../../references/end_to_end.md)，或运行本地界面：

```bash
python -m streamlit run scripts/workflow_app.py --server.address 127.0.0.1 --server.port 8513
```

本机本轮完整产物位于 `output/mil53_workflow_run3/`，输入配置位于
`output/mil53_demo_config_v2/workflow.json`；这些大型中间产物不纳入代码仓库。
公开来源、模型哈希和归一化数值已保留在本目录，不能把其分类改写为“成功预测开门压力”。
